\# Folders \& Organisation



Organise your workspace exactly how you like it.



\- \*\*Sidebar Navigation:\*\* Use the arrow keys to open folders or navigate notes. The \*\*Right Arrow\*\* jumps straight from a note title into the editor.

\- \*\*Drag \& Drop:\*\* Click and hold any note or folder to move it. 

\- \*\*Ejecting:\*\* Drop an item onto the empty space at the bottom of the sidebar to move it back to the main root level.
