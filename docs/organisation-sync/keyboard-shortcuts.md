\# Keyboard Shortcuts



Master Redly with these speed-focused shortcuts.



| Action | Shortcut |

| :--- | :--- |

| \*\*Home Screen\*\* | `ALT + H` |

| \*\*New Note\*\* | `ALT + N` |

| \*\*New Folder\*\* | `ALT + F` |

| \*\*Focus Sidebar\*\* | `ALT + S` |

| \*\*Focus Editor\*\* | `ALT + E` |

| \*\*Rename Note/Folder\*\* | `ALT + R` |

| \*\*Global Task View\*\* | `ALT + T` |

| \*\*Toggle Kanban/List\*\* | `ALT + V` |

| \*\*Filter Tags\*\* | `ALT + G` |

| \*\*Insert Template\*\* | `INSERT` |

| \*\*Open Guide\*\* | `ALT + /` |
