\# Writing in Redly



Redly uses simple text formatting that is industry standard.



\### Slash Commands

Type `/` inside any note to open the rich formatting menu. This allows you to add:

\- \*\*Headings\*\* (H1, H2, H3)

\- \*\*Lists\*\* (Bulleted and Numbered)

\- \*\*Blockquotes\*\* for highlighting text.

\- \*\*To-do items\*\* for your tasks.
