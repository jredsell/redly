\# Tables



To insert a table, type `/` and select \*\*Table\*\*. Redly will insert a 3×3 grid with a header row.



\### Managing Tables

\- \*\*Navigation:\*\* Use \*\*Tab\*\* to move between cells.

\- \*\*Toolbar:\*\* When you click inside a table, a toolbar appears at the top-right of the editor. Use this to add or remove rows and columns effortlessly.
