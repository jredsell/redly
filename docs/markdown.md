# Writing Markdown

Redly natively supports standard Markdown syntax. Here is a quick reference on how to format your notes.

## Headers

```markdown
# H1
## H2
### H3
```

## Formatting text

You can make text **bold** or *italic*.
```markdown
**bold**
*italic*
```

## Code

You can format code using backticks. Use triple backticks for code blocks.

```javascript
function helloWorld() {
  console.log("Hello, world!");
}
```

## Checklists and Tables

```markdown
- [x] Completed task
- [ ] Incomplete task

| Feature | Support |
|---------|---------|
| Syncing |   Yes   |
| Tables  |   Yes   |
```
