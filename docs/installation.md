# Installation

### Supported Browsers
Redly is deeply integrated with modern File System Access APIs. For the best experience using Local Storage (where files are saved visibly on your hard drive), use **Chrome, Edge, or Opera**. 

If you use Firefox, Safari, or a Mobile Device, you can still use the **Browser Storage** option which runs perfectly in a secure sandbox.

### Desktop App Setup
To install Redly as a native desktop application, open Redly in Chrome or Edge and click the **Install Redly App** button on the home screen.

### Mobile App Setup
Open Redly in Safari (iOS) or Chrome (Android). 
- **iOS:** Tap the Share button in the toolbar, scroll down, and select "Add to Home Screen".
- **Android:** Tap the Menu icon, and select "Install page as app" or "Add to Home Screen".
